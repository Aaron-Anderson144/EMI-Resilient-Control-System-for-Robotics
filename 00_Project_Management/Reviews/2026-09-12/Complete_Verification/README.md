# Complete verification record

This folder contains the report, tests, audit results and summary tables from the 12 September 2026 verification. Start with [Verification_Report.md](Verification_Report.md).

The full raw MATLAB, circuit and trajectory evidence is retained in the standalone verification folder named by `evidence_root` in [evidence_index.json](evidence_index.json). This compact project copy intentionally omits those large raw files and solver caches. The evidence index describes the full standalone folder; `compact_copy_manifest.json` lists this copy.
