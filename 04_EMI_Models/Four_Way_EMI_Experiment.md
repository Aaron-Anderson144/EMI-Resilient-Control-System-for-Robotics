# Frozen First Four-Way EMI Experiment

**Design ID:** FOUR-WAY-EMI-PLAN-V1. **Frozen:** 2026-09-10, before integrated development or evaluation runs. **Status:** design only; A01 / RES-005 and the A02 causal-interface implementation remain open. This document specifies a first conditional numerical comparison, not a hardware immunity claim or an approved requirement. Existing controller/model defaults are unchanged.

## Question and boundary

For a declared external switching-voltage replay coupled capacitively into one encoder A pair, does adding differential capacitance, the historical protected software policy, or both reduce decoded-count and actuator-task disturbance? Compare all four arms with identical external excitation and task definitions. A result of no persistent decoding error, no control effect, or no combined advantage is valid evidence; do not increase exposure or choose a different filter after seeing evaluation results.

The aggressor is an independent one-way replay of a separate R2 commutation cell. Its load is not this actuator's winding. This first experiment does not feed controller commands back into the switching source, model a complete encoder cable or CAN physical layer, or cover inductive/common-impedance aggressor injection. A clean ideal B bit isolates corruption of one A receiver pair. This limited topology advances a causal bridge; it does not satisfy all charter coupling paths or physical validation.

## Receiver, quadrature and causal sampling

Use an explicitly assumed Schmitt receiver: output A sets high at `vp-vn >= +0.20 V`, low at `vp-vn <= -0.20 V`, and holds between. These illustrative levels acquire a new behavioral meaning here; prior band-crossing reports did not validate a decoder. There is no minimum-pulse filter or assumed 50 ns rejection. An excursion outside `abs((vp+vn)/2) <= 7 V` is a model-domain failure: retain the run as rejected diagnostics, hold A only to finish recording, and do not interpret that fallback as actual receiver behavior.

Let `delta=2*pi/4096` rad and intended integer count `q=floor(theta/delta + 0.5)`. Thus 4096 means decoded x4 counts/revolution, or 1024 A cycles. Zero position starts at the center of a quantization bin, q=0, A=B=0, decoded count=0. Positive count order is `00 -> 10 -> 11 -> 01 -> 00`; negative motion reverses it. The intended B bit is ideal and clean; only A traverses the electrical network. This ideal B path has no physical cable loading or independent corruption in this bounded model.

Generate each intended quadrature transition from the current continuous plant trajectory. Between 1 ms control updates, the currently held voltage and known load determine the exact affine motor solution; locate every angle-boundary crossing, including an interior reversal. Do not infer transitions from coarse endpoint positions or a future full-run trajectory. At a crossing use the direction-aware right-hand trajectory limit; a tangency that stays in the same bin is not a transition. Exactly coincident A/B changes are processed as a joint state change, without arbitrary tie ordering. The decoder increments +1/-1 for adjacent Gray transitions, increments zero for unchanged states, and increments zero plus an invalid-transition counter for a two-bit change. After every observed joint change, including an invalid one, it updates its previous A/B state to that observed state. That resynchronization makes no additional count change beyond the valid increment already specified; invalid changes hold count, and no offset is repaired. Root times equal within 1 ps are treated jointly and this convention is included in refinement tests.

Resolve receiver threshold events and decoder transitions before any controller sample at the same timestamp. At k*Ts, k=0..3000, emit the current persistent decoded count times delta, with fresh source index k+1 (the existing one-based convention). Never repair counts from true angle or clear count error at exposure end. A transient A toggle and return with B fixed can cancel its net count effect; both edge activity and persistent error must be recorded. Control receives only the decoded measurement, source index/receipt, applied command, bus, shaped reference and scheduled reset. True state belongs only to plant/sensor generation and offline scoring. Fault masks, ideal count, count error, source exposure and receiver-domain flags do not enter controller decisions.

The present `phase3_loop_step` constructs a continuous-angle sensor internally. A separately tested measurement-input boundary/adapter is required before using this contract. Merely adding a precomputed error to that sensor is not the closed-loop circuit/decoder implementation specified here. Preserve legacy results when the new interface is unused; do not silently replace existing fixture semantics.

## Frozen metrics and decision

Report original-request tracking and shaped-command tracking separately. For each arm subtract its own clean trajectory at matched times to obtain disturbance delta. Fixed scoring windows are `[0.24,0.40)` and `[1.69,1.85)` s (union, not adaptive to alarms). Report paired position RMSE and peak there, full-record and tail errors, actual speed/current peaks, integral i^2 dt, command/cap/slew activity, ideal-minus-decoded count peak/final, and extra/missing/invalid transition counts. Error versus ideal quantized count and continuous-angle quantization error are separate columns. Report individual fixture results before aggregates; supply the raw records needed for independent recomputation.

Recovery is scored separately after each burst: the first50 ms dwell after that burst's last actual nonzero dVa/dt in which paired position error is <=0.5 degree; protected arms additionally require normal mode throughout that dwell. Report both elapsed times and censoring. Both bursts must recover within0.5 s for task success; a later second-burst recovery does not erase first-burst non-recovery.

For EMI attribution, run an offline no-aggressor shadow receiver/decoder on the **same exposed run's intended A/B trajectory**, with the same Cd, initial state, thresholds and decoder semantics. It never feeds control. First corrupted packet means the exposed decoded count differs from this own-trajectory shadow count; ordinary receiver propagation delay is present in both. The separate matched-clean plant trajectory remains the task comparator and is not used as the decoder oracle after trajectories diverge. Preserve ideal quantized count, shadow decoded count and exposed decoded count as distinct channels. Detector delay starts at the first corrupted controller sample of each new disagreement episode (zero-to-nonzero error); continuing corruption from an earlier burst is labeled pre-existing, not a new opportunity. No disagreement means no detectable-fault opportunity. Pre-existing alarms do not earn credit; record missed opportunities, censoring and exposed/clean false alarms.

For this first comparison, an exposed arm has **task success** only if execution/clean guards pass, paired window RMSE<=0.5 degree, paired window peak<=2 degrees, final requested error and final-0.1-s requested RMSE<=0.5 degree, and each burst's recovery<=0.5 s. These thresholds are predeclared research choices; current/thermal/physical safety limits remain unidentified.

The combined-benefit hypothesis is supported **within this fixture** only if all execution/clean guards pass; define shared per-fixture denominator `d_i=max(baseline_window_RMSE_i,0.25 degree)` and require `mean(combined_window_RMSE_i/d_i) <= 0.90*mean(baseline_window_RMSE_i/d_i)` over the12 evaluation fixtures; combined RMSE/peak in each fixture does not exceed baseline by more than max(10% of baseline,0.25 degree); and combined peak current does not exceed baseline by more than max(10% of baseline,0.05 A). In addition, at least one baseline task failure must become a combined task success. Both sides use the same denominator, including floored rows; comparing the combined normalized mean merely to0.90 is invalid. Report raw aggregate RMSE as well as the declared normalized aggregate. The explicit rescued-failure condition prevents nearly zero errors in every arm from being advertised as increased tolerance. Report EM_ONLY and SW_ONLY on the same metrics and task gates; combined equality with EM_ONLY does not establish synergy or a software benefit.

If baseline succeeds at all levels, receiver glitches cancel, or the benefit criteria fail, report **not demonstrated at the frozen exposures**, with the actual results. Do not delete these cases or tune on them. Report tolerance by task/sign/phase and the largest contiguous tested passing Ccp prefix; nonmonotonic holes require per-case reporting, all-pass is right-censored at 300 pF, and all-fail is below the lowest tested 30 pF. These are deterministic conditional results, not a physical immunity boundary.
