# Bundled reference motor

These files are unchanged copies of the representative motor parameters and the two functions needed to validate and build the model. They let the hybrid experiment run without the original project checkout.

The parameters describe the project's assumed DC-equivalent motor. They have not been identified from a new physical actuator. See [provenance](../PROVENANCE.md) for the source and [the results](../docs/RESULTS.md) for the simulated variation ranges.
