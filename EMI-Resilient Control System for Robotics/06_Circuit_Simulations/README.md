# Circuit Simulation Plan

This folder is reserved for LTspice, Simscape Electrical, or equivalent circuit-level models.

## Planned Circuits

1. Controller power input and decoupling
2. Encoder receiver with RC filtering and protection
3. CAN transceiver and termination network
4. Shared ground and supply impedance
5. Cable parasitic network
6. Common-mode choke and isolation comparison
7. Motor-drive switching-node coupling into a victim signal

## Required Outputs

- Circuit schematic
- Parameter and model-source list
- Transient waveform
- Frequency response where applicable
- Disturbance attenuation
- Propagation delay or bandwidth penalty
- Assumptions and validity range

Do not infer radiated EMC compliance from a lumped circuit model.
